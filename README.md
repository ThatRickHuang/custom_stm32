# Custom STM32

Custom STM32 PCB design for KiCad 10.

Open `custom_stm32.kicad_pro` in KiCad to access the schematic and PCB layout.

- `custom_stm32.kicad_pro`: project settings.
- `custom_stm32.kicad_sch`: schematic recovered from local project history.
- `custom_stm32.kicad_pcb`: PCB layout.

Manufacturing exports, reference downloads, and local editor files are excluded from this repository.
